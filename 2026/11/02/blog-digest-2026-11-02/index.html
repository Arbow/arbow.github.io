这篇文章目前是一个明显未完成的草稿：页面标注”少于 1 分钟阅读”，简介一节直接写着”（未整理）”，目录里列了”主动性””主动性的关键在收敛””架构””super-agent”几个小节，但只有最后的 super-agent 一节有正文，前面几节都只有标题。所以下面的分析只能基于这一节，标题里的”自进化”在正文里还没有展开。

super-agent 一节的论点是：传统 Agent 以单个 Session 为单位工作，Session 之间互相独立，用户并行推进多项工作时要自己切换、自己记住各个会话的上下文，一个人通常只能同时跟进 3 到 5 个活跃 Session。于是”单任务的上限取决于模型能力，多任务的上限取决于人的注意力”。要突破这一点，就得让 Agent 脱离单次手动会话，成为一个跨会话保持上下文、能同时推进多项任务的连续实体，即 Super-agent。文中给出四个特征：连续（在 IM、GitHub 评论等界面交互，感觉始终只有一个 Agent）、高效（不等上一个任务完成就能接下一条指令）、主动（持续观察环境事件，不需要时保持安静）、持久（始终在线、接入真实工作环境、异常自动恢复）。最后一段指出单个 ReAct Loop 撑不起这四点，并认为这类系统会面对很多传统计算机系统早已讨论过的问题，经典设计思想同样适用。

需要说明的是，这一节用的是”我们把这种 Agent 形态……称为 Super-agent”的第一人称口吻，内容与 DeepSeek Harness 团队的《Super-agent 设计探索》开篇高度一致（3 到 5 个会话、注意力瓶颈、四个特征），但帖子本身没有注明出处。本站昨天正好转了那篇长文，见《文摘：DeepSeek Super-agent 设计探索》，想看完整架构、实验数据和局限的，直接读那篇更合适。
