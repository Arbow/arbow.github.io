文摘：从 GPT-2 到 KimiK3，七年的架构演进

Jul 28 2026 文摘

引言

22,580 倍——这是 KimiK3 (2026) 相对于 GPT-2 (2019) 的规模增长。但仅仅归因于规模是错误的。这篇文章从实现层面梳理了七年间 Transformer 架构的关键演化路径，揭示了每一代模型在解决什么问题、如何演进到今天的形式。

核心洞察

GPT-2: 基石

GPT-2 的结构非常简洁：

  • token 嵌入 + 位置嵌入
  • 12 层 transformer block（每层：LayerNorm → Self-Attention → LayerNorm → MLP）
  • 约 124M 参数（vocab_size=50304, n_layer=12, n_head=12, n_embd=768）

KV Cache 的引入解决了自回归解码的效率问题。解码时只使用最终位置的 logits，但需要缓存所有历史 token 的 K、V 向量以避免重复计算。这带来了内存带宽瓶颈——KV cache 随序列长度 O(N) 线性增长。

Linear Attention: O(N) 的尝试

标准 attention 在 softmax 之前计算 q·k，需要构建完整的 N×N 矩阵（FlashAttention 之前）。Linear attention 改变了这一点：

  • 对 q 和 k 分别应用特征映射（如 ELU+1）而非 softmax
  • 这使 q·k·v 可以重组合并：S = ∑ kᵀv，z = ∑ k，输出 o = qS / (qz)
  • 状态始终是固定的 D×D 矩阵，不再随 N 增长

代价：特征映射是 softmax 的近似，表达能力较弱。此外，状态容量固定，当 N ≫ D 时，纯加法更新会导致信息互相干扰——没有”驱逐”机制，旧事实永不消失。

DeltaNet: 精确修改

DeltaNet 解决了固定容量记忆的驱逐问题。核心思想：当写入新事实时，先读取该 key 位置已存储的信息，计算差值，用差值更新。

β 是 sigmoid 生成的门控，控制写入强度。这让模型可以精确替换单个 key-value 关联，而非盲目叠加。

训练问题：Delta rule 依赖当前状态，无法直接并行化。作者通过重新参数化（引入广义 Householder 过渡矩阵）实现 chunk-wise 并行，使训练成本从 O(N²) 降至 O(N)。

Gated Delta Net: 结合精确与遗忘

Mamba 的门控更新提供了一个思路：cache = α * cache + new，α ∈ [0,1] 控制全局遗忘。但 Mamba 无法”只忘一个”，要么全忘，要么都留。

Gated Delta Net 的方案：结合两者优势——Delta rule 负责精确修改，α 控制整体衰减。实现上，对每个 token 使用数据依赖的 α_t，累计衰减为前序 α 的乘积，类似前缀和的乘法形式。

这既保留了单个关联的精确更新能力，又能根据需要整体衰减记忆。

Kimi Linear: 细粒度门控

Kimi Linear 在 Gated Delta Net 基础上进一步改进：不是用单个标量 α，而是对每个 channel 使用独立的衰减值。alpha.reshape(nb, C, d) 让模型对记忆的每个维度有细粒度控制。

此外，Kimi Linear 是混合架构：

  • 交织 KDA (Kimi Delta Attention) 和 MLA (Multi-head Latent Attention) 层
  • 用 MoE 替换 MLP
  • 通过 alpha 投影增加容量

这不是盲目的 scaling，每处容量增加都有明确目的。

KimiK3: 集大成

KimiK3 的最终架构：

  • 23 个四层宏周期（macrocycles）
  • 每个宏周期：3 层 KDA + 1 层 MLA
  • 首层使用 dense FFN，其余层使用 latent MoE（共 898 个专家，每 token 激活 16 个 + 2 个共享专家）
  • 每 12 层做一次 AttnRes（Attention Residuals）
  • MLA query LoRA + 输出门控
  • SiTU 激活函数

AttnRes 是一个关键创新。传统残差连接 h_l = h_1 + ∑ f_i(h_i) 让所有层权重相同。AttnRes 引入可学习的权重 α_i，让每层能选择性检索之前层中最有用的表示：

每 12 层执行一次，捕获大部分收益同时控制开销。

总结

从 GPT-2 到 KimiK3 的演进，不是”越大越好”的简单故事，而是对固定容量关联记忆机制的持续优化：

架构 解决的问题 关键机制
Linear Attention O(N²) 复杂度 固定 D×D 状态
DeltaNet 无驱逐机制 精确差值更新
Gated Delta Net 无法整体遗忘 门控衰减
Kimi Linear 粗粒度控制 Per-channel decay
KimiK3 固定容量的召回能力 KDA + MLA + AttnRes + MoE

固定容量记忆需要驱逐策略——纯加法操作最终会满载并互相干扰。学到选择（gating、routing、decay）是必要的，而 attention 是最有效的选择性读取机制。

KimiK3 的核心变化不是规模，而是将额外容量投入有明确功能角色的地方：常量状态循环记忆 + 周期性 softmax 召回 + 稀疏专家容量 + 选择性深度残差访问。
