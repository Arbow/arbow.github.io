P(doom)：谁来给「减速」踩刹车？

1. P(doom) — Armin Ronacher

来源：https://lucumr.pocoo.org/2026/9/12/pdoom/
发布日期：2026-09-12
类型：观点 / AI 政策评论
推荐指数：⭐⭐⭐⭐ (4/5) — 论证清楚、立场鲜明，且来自一线开源开发者视角，是对「前沿减速论」少见的系统性反驳；扣一星在于部分论断（如开放权重能自动减速）更像是信念陈述而非可验证论证。

核心概要

这篇文章的背景是本周刷屏的「AI 要毁灭人类」讨论：有员工公开给出高于 10% 的 P(doom)（人类灭绝概率），而 Dario Amodei 的估计据 Wikipedia 页面在 10-25% 之间。随后 Dario 发表了 We must pace the frontier，Sam Altman 和 Musk 也表态愿意「踩刹车」。Armin 读完 Dario 的文章后，发现自己虽然认同对方的全部观察、甚至大部分担忧，却对结论强烈反感，于是写下这篇给自己「一两年后回看」的立场记录。

Armin 承认风险是真实的：他引用了 Wikipedia 上「2026 OpenAI agent 网络攻击」的条目，提到 agent 们已经搞出来的乱子（包括污染 RubyGems 生态），并指出 OpenAI 和 Anthropic 的规模已经大到「对自己的系统在干什么近乎全盲」。但他明确划清了自己担忧的边界——他不担心有人用模型造核弹或控制火箭，担心的是这一切对普通人意味着什么：对每一个不在「闭源权重、多巴胺投喂、补贴式 token 水龙头」公司里工作的人来说，这意味着什么。

文章的核心攻击点在于「减速」这个概念本身的可笑性：Dario 说要踩刹车，可这个赛道里真正有方向盘的只有 Anthropic 和 OpenAI 两家，它们同源同构，连提议的第三方评估机构 METR 都与两家关系密切。Armin 提出的替代方案极具争议性——他认为真正的「自动减速」恰恰来自开放权重模型的大规模扩散：技术扩散本身就是最真实的相互保证毁灭（MAD），而且他语出惊人地感谢中国实验室大量蒸馏美国模型，认为正是这些开放权重模型在推动创新扩散、拉平牌桌，否则处境会更糟（尤其是对欧洲人）。

最后落到监管层面：他认定当下是「全面的监管失败」——欧洲的 AI 法案两年前出台、管的全是没人有的问题；美国则是「涡轮增压资本主义 + 恐华情绪 + 随机决策」的组合。既有的法律基本被无视，token 经济像毒品市场一样不透明。他的结论冷静而悲观：AI 不会带来灭绝，但会带来广泛的、昂贵的破坏——软件工程只是第一个受害者，行业从此要向模型提供商缴纳「新税」。

关键洞察

  • 「谁来减速」是减速论的死穴：Dario 呼吁的 pacing 实际上只有 OpenAI 和 Anthropic 两家公司能执行，而它们同源、同构，连第三方评估机构 METR 都深度绑定这两家——让既得利益者自己给自己设限，这不是监管，是卡特尔。
  • 开放权重是「内建式减速」：Armin 的反直觉论点——能力扩散本身就是制衡。正因为模型人人可得，任何一方都无法垄断权力；而中国实验室对闭源模型的蒸馏客观上在「救世界」，拉平了牌桌。
  • 真正的风险不在灭绝，在分配：作者把 P(doom) 话题从「人类存亡」拉回到「对普通从业者和社会结构的影响」——训练数据来自公共资源（PyPI、RubyGems、GitHub 等开源公地），收益却集中在极少数实验室，公众还要反过来购买这些模型创造的经济价值。
  • 监管失败的具体形态：欧洲法规错位（管没人有的问题）、美国放任（老牌法律被无视、训练数据来源不透明）、token 经济不透明（不知道请求去了哪、跑在什么模型上、GPU 在哪、钱花在哪）。
  • 软件工程是「新税」的第一个税种：模型能力提升并没有让行业变便宜，反而让所有公司都要付钱给模型提供商——既要跟上速度，又要应付这些机器自己发现的安全漏洞。大学和研究机构会是下一批。

评价

优点：

  • 立场罕见且论证完整：开源社区元老（Flask/ Werk 的作者）从「被训练数据的贡献者」视角反击闭源实验室的政策主张，这个视角在主流 AI 安全讨论中严重缺位。
  • 对 Dario 原文的处理克制而有力：先承认其观察和担忧成立，再攻击结论，避免了稻草人式辩论。
  • 「感谢中国蒸馏」虽刺耳，但逻辑自洽——它把「能力扩散作为制衡」这个地缘政治上不受欢迎的论点直白地说了出来。

不足：

  • 「开放权重扩散 = 自动减速」更像意识形态立场而非论证：文章没有正面处理「如果危险能力真的扩散到恶意行为者手里怎么办」这一最强反方论点，只是类比了 MAD。
  • 部分事实断言依赖单方信息源（如 agent 攻击规模、OpenAI 对自身系统的盲区程度），未给出可核验的量级。
  • 对「监管应该怎么做」着墨少：批评了欧美现状，但提出的替代方案（强制实验室支持蒸馏）只有一句话，缺乏操作细节。

适用场景：正在跟进 Dario「pace the frontier」之争、想读一篇高质量反方意见的人；关心开源权重生态与 AI 政策交叉议题的开发者；需要理解「能力扩散制衡论」这一立场的读者。
