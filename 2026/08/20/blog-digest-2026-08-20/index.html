1. What Is Reasoning — 推理痕迹到底是什么

来源: Armin Ronacher（Flask 作者）
发布日期: 2026-08-19

核心概要

几周前一篇论文展示了如何从闭源权重模型中提取推理痕迹（reasoning traces），加上社交网络上各种”骗模型吐出思考过程”的讨论满天飞，Armin Ronacher 由此写下这篇短小精悍的文章，把”推理”在模型层面到底发生了什么讲得清清楚楚——用他自己的话说：Twitter 上满是半真半假的说法，希望这篇能帮人理解实际发生了什么。

文章的第一个祛魅是：推理痕迹一点也不神秘，它就是普通文本。以 GPT-OSS 的 Harmony 响应格式为例，模型被训练成在 analysis 通道里写草稿、在 final 通道里给答案，通道切换靠的是特殊 token 标记，而标记之间的思考内容和最终答案用的是”同一种文本”。闭源模型隐藏思考过程，本质上是一个解析器把 analysis 通道路由到单独的流（Responses API 暴露），再推测经过一层模型做脱敏与摘要。

第二个祛魅是关于”推理预算”：早期 API 暴露的 reasoning token budget 让人以为这是采样过程的属性，实际上推理力度（reasoning effort）是被烤进 system prompt 的——GPT-OSS 的做法干脆就是在系统提示里加一句 Reasoning: low，剩下的交给训练出的行为。这顺便解释了一个很多人观察到的现象：为什么调整推理力度会让 KV cache 失效——因为 prompt 变了，缓存自然作废。作者还提到闭源 GPT 模型内部把推理力度称作 “juice”，直接问模型自己还剩多少 juice，它通常能答上来。

最后一节讲”如何不思考”：推理 token 的去向是一个习得的约定——模型被训练成不在 final 通道写草稿，所以骗模型”以为自己在 final 通道”就可能让它泄露思考。禁用思考的实现往往很”机械”：比如 DwarfStar（antirez 给 DeepSeek 写的推理引擎）在禁用思考时直接预填充 </think>，让模型从思考块外面开始生成；而某些推理 API 在开启思考时预填充起始 token，让模型永远不自己采样它。这也解释了为什么自定义 think 工具能把推理”骗”到不该去的地方——但只在原生推理被禁用时有效。

关键洞察

  • 推理痕迹只是文本：模型在特殊 token 标记的 analysis 通道里写草稿，与 final 通道用同一种文本；”神秘感”来自 UI 展示层和闭源模型的隐藏策略，而不是模型本身有什么特殊机制
  • 推理力度是 prompt 约定：GPT-OSS 在 system prompt 里写 Reasoning: low 即可实现力度控制；DwarfStar 给 DeepSeek 用的是更戏剧化的 “Reasoning Effort: Absolute maximum with no shortcuts permitted” 长指令
  • KV cache 失效是反向证据：改推理力度导致缓存失效这个可观测现象，反过来印证了”力度就是 prompt 的一部分”，而非采样参数
  • 禁用思考靠预填充：</think> prefill 让模型从思考块外开始；有 API 在开启思考时预填充起始 token——模型从不自己采样推理开关 token
  • “隐藏思考”不是密码学保护：闭源模型靠路由 + 脱敏摘要来隐藏推理，是习得约定加事后过滤，所以论文的提取方法和 think 工具的诡计才可能奏效

评价

优点：

  • 短、准、有实锤：用 Harmony 格式的原始 token 标记、DwarfStar 的 prefill 实现做证据，不是空对空的概念炒作
  • 把”推理力度””思考禁用”这些被 API 文档包装成黑盒参数的东西，还原成 prompt 约定 + 训练行为，读完认知负担骤降
  • 结尾彩蛋极其真实：GPT-5.6-terra 因为安全过滤器拒绝给这篇博文做拼写检查，作者只能换 Kimi——安全策略误伤日常工作的活例子

不足：

  • 篇幅很短，对论文本身的提取技术细节几乎没展开，想复现的话信息量不够
  • 关于闭源模型的部分是基于开源模型行为的外推（作者自己也用了 “presumably”），闭源内部实现仍是推测
  • 对不关心 LLM 内部机制的读者吸引力有限

适用场景：正在做 Agent / 推理相关工程、想理解 reasoning effort 与 KV cache 失效关系、或需要对”思维链保密性”话题做技术判断的开发者。

推荐指数

⭐⭐⭐⭐ (4/5)

理由：Flask 作者出手的一手技术祛魅，证据扎实、结论可直接用于工程判断，对 LLM 工程师来说是高信号密度的阅读。扣一星是因为它是一篇单主题短文，覆盖面窄，且对提取论文的核心方法着墨少——达不到”必读”级别，但绝对值得一读。
